# 🌐 HƯỚNG DẪN ĐƯA TRANG WEB LÊN GITHUB PAGES (MIỄN PHÍ 100%)

Phiên bản này được thiết kế theo đúng yêu cầu: **chạy 100% trên nền tảng lưu trữ web của GitHub (GitHub Pages)**, không cần máy chủ backend, không cần quét mã QR, chia sẻ liên kết trực tiếp để tải phai.

---

## ⚡ CÁC BƯỚC ĐƯA LÊN GITHUB CHỈ TRONG 2 PHÚT

### 🔹 Bước 1: Tạo Repository (Kho chứa) trên GitHub
1. Đăng nhập vào tài khoản GitHub của bạn tại [github.com](https://github.com).
2. Bấm vào nút dấu cộng `+` ở góc trên bên phải -> chọn **New repository** (hoặc truy cập: [github.com/new](https://github.com/new)).
3. Điền các thông tin:
   - **Repository name**: Đặt tên bất kỳ bạn thích, ví dụ: `my-fsend` (hoặc `chiasephai`).
   - Chọn chế độ: **Public** (Công khai).
4. Bấm nút xanh **Create repository**.

---

### 🔹 Bước 2: Tải các file lên GitHub
1. Trong trang kho chứa vừa tạo, bấm vào dòng chữ **"uploading an existing file"** (hoặc bấm `Add file` -> `Upload files`).
2. Mở thư mục `WebChiaSe_GitHubPages` trên máy tính, chọn 4 file sau và **kéo thả vào trình duyệt**:
   - ✅ `index.html`
   - ✅ `style.css`
   - ✅ `app.js`
   - ✅ `peerjs.min.js`
3. Cuộn xuống dưới cùng và bấm nút xanh: **Commit changes**.

---

### 🔹 Bước 3: Bật tính năng GitHub Pages (Kích hoạt trang web)
1. Trên thanh menu ngang của Repository, bấm vào tab **Settings** (biểu tượng bánh răng).
2. Ở cột danh mục bên trái, cuộn xuống và bấm vào mục **Pages** (trong phần Code and automation).
3. Tại phần **Build and deployment**:
   - Mục **Branch**: Chọn nhánh **`main`** (hoặc `master`).
   - Thư mục bên cạnh: Giữ nguyên là **`/(root)`**.
   - Bấm nút **Save**.
4. Chờ khoảng 30 giây đến 1 phút rồi F5 (tải lại trang). Bạn sẽ thấy thông báo:
   🎉 *"Your site is live at `https://<ten-tai-khoan>.github.io/my-fsend/`"*

---

## 🚀 3 BƯỚC SỬ DỤNG TRANG WEB ĐÚNG YÊU CẦU:

1. **Vào trang**: Có sẵn nút **"Chọn Phai Từ Máy Tính"** hoặc kéo thả phai vào ô.
2. **Sau khi tải phai lên**:
   - Hiển thị rõ **Tên phai** và **Dung lượng phai**.
   - Có ngay nút to nổi bật: **📋 SAO CHÉP LIÊN KẾT ĐỂ GỬI** (bấm 1 cái là liên kết tự sao chép vào bộ nhớ tạm, **hoàn toàn không cần quét bất kỳ mã QR nào**).
3. **Khi gửi liên kết cho người dùng**:
   - Người nhận bấm vào liên kết sẽ thấy ngay **Tên phai**, **Dung lượng phai** rõ ràng.
   - Có nút **📥 TẢI PHAI XUỐNG NGAY** để người nhận bấm tải phai về máy lập tức.

*(Lưu ý: Dữ liệu truyền trực tiếp từ máy của bạn sang người nhận qua trình duyệt, bạn chỉ cần giữ tab web mở trong khi người nhận đang tải nhé)*.
